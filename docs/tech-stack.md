## フロントエンド

### フレームワーク

| 技術 | バージョン | 用途 | 選定理由 |
|------|-----------|------|---------|
| **Next.js** | 14.x (予定) | フレームワーク | 静的サイト生成（SSG）に対応、Reactベースで開発効率が高い |
| **React** | 18.x (予定) | UIライブラリ | コンポーネントベースの開発、豊富なエコシステム |
| **TypeScript** | 5.x (予定) | 言語 | 型安全性の確保、開発体験の向上 |

## バックエンド

### 現時点での方針

- **バックエンド**: 不要（静的サイトとして構築）
- **データベース**: 不要（JSONファイルで管理）

### 将来の拡張時（検討事項）

| 技術 | 用途 | 選定理由 |
|------|------|---------|
| **Next.js API Routes** | APIエンドポイント | Next.jsと統合しやすい |
| **PostgreSQL** / **MongoDB** | データベース | 記事データの永続化 |
| **NextAuth.js** | 認証 | Next.jsと統合しやすい |
| **Meilisearch** / **Elasticsearch** | 検索エンジン | 高度な検索機能の実装 |

## データ管理

### データ形式

| 技術 | 用途 | 選定理由 |
|------|------|---------|
| **JSON** | 記事データの保存 | シンプル、読み書きが容易、静的サイトに適している |

### データ保存場所

- **記事データ**: `data/articles/`フォルダ
- **メタデータ**: `data/articles-index.json`（ビルド時に自動生成）
