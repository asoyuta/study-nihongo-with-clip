# ドキュメント一覧

## 📚 ドキュメント一覧

### プロジェクト概要

- **[要件定義書](./requirements.md)**
  - プロジェクトの要件と仕様を定義
  - 機能要件、データ構造、実装フェーズ等

### 技術情報

- **[技術スタック](./tech-stack.md)**
  - 使用する技術の一覧と選定理由
  - バージョン情報、参考リンク

- **[プロジェクト構造](./project-structure.md)**
  - ディレクトリ構造とファイル構成
  - 命名規則、データファイル構造

- **[開発ガイドライン](./development-guide.md)**
  - 開発環境のセットアップ
  - コーディング規約、Git運用

### プロジェクト管理

- **[進捗管理](./progress.md)**
  - フェーズごとの進捗状況
  - タスクリスト、ブロッカー管理

---

## 🚀 クイックスタート

1. **[要件定義書](./requirements.md)** を読んでプロジェクトの全体像を把握
2. **[技術スタック](./tech-stack.md)** で使用技術を確認
3. **[開発ガイドライン](./development-guide.md)** で開発環境をセットアップ
4. **[進捗管理](./progress.md)** で現在の進捗を確認

---

## 📝 ドキュメントの更新

ドキュメントは定期的に更新してください。特に以下のタイミングで更新を推奨します：

- 要件が変更された時 → `requirements.md`
- 技術スタックが変更された時 → `tech-stack.md`
- タスクが完了した時 → `progress.md`
- プロジェクト構造が変更された時 → `project-structure.md`
- 開発ルールが変更された時 → `development-guide.md`
